- **Binomial/Bernoulli fixed-effect fits are now screened for (quasi-)complete separation: detect and warn (#731, #728).** A fixed-effects-only `Binomial()` fit runs the Albert–Anderson / Konis (2007) separation check on the signed design (`X̃ d ≥ 0` for some `d ≠ 0`; a non-negative least-squares solve, no new dependency — see the #910-review fragment). When the maximum-likelihood estimate does not exist the fit is still returned, a warning names the coefficients that can diverge (`flagged_coefficients`), and their standard errors are `Inf` (their vcov rows/columns are NaN). Near separation is flagged the same way, on the scale-free rule described in the #910-review fragment. No refusal and no Firth/MSPL by default. drmTMB (#1268) runs the same check with the same constants, so the twins flag the same coefficients; coefficient values under separation are arbitrary stopping points and are not expected to agree. Random-intercept binomial routes are not screened. Non-separated fits are unchanged.
