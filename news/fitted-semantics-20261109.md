- **`fitted()`, `residuals()` and `predict()` now mean what drmTMB's do for LogNormal, zero-inflated, hurdle and zero-truncated fits.** `fitted(fit)` returns the response mean `E[Y]`: `exp(μ + σ²/2)` for `LogNormal`, `(1 - π) μ` for zero-inflated Poisson / NB2, `μ / (1 - P(0))` for zero-truncated NB2 and truncated Poisson, and `(1 - π) μ / (1 - P(0))` for hurdle Poisson / NB2. It returned `exp(μ)` or the component `μ` before, so the same converged model reported a different mean from R (gap map v2, 104 cells with equal logLik). `residuals(fit)` is `y - fitted(fit)`. `predict(fit, newdata)` gains `type = :mean` (`E[Y]` at new rows, drmTMB's `type = "mean"`) and `type = :median` (LogNormal `exp(μ)`); `type = :response` stays the response scale of the location parameter (the count component mean for the count families), and for `LogNormal` it is now the log-scale `μ`, equal to `type = :link`, as in drmTMB (use `type = :median` for the old `exp(μ)`). `fit.means[:mu]`, `simulate`, `predict_parameters` and the R bridge payload are unchanged.
