- **`check_drm`'s SkewNormal `skew_normal_nu_wald` note now follows the shared drmTMB rule (drmTMB#1540, #1336).** It fires when every fitted |ν̂| < 0.5 OR a 95% joint Wald χ² test that the `nu` block is 0 does not reject (a test that cannot be formed does not reject). Previously it fired when any single |ν̂| < 0.5 and ran no Wald test, so a fit with one near-zero row but a clearly non-zero slant was flagged. The report gains `all_below`, `wald_rejects`, `wald_stat`, `wald_df`, `wald_pvalue`, `level` and `max_abs_nu`, and the warning names the arm that fired.
