- **Univariate Gaussian `missing = miss_control(response = "include")` is accepted (P53c).** It used to stop with "`impute` and `missing` controls currently require an additive mi(x) joint-model formula". It now follows the same design as the bivariate include (train 4): a row with a missing response stays out of the likelihood (a Gaussian response with independent rows integrates out), carries `NaN` in `fit.obs[:mu]` (read by `_used_row_mask`), and `fitted`, `residuals`, `sigma` and quantile residuals return the used rows (`nobs(fit)`). The estimates equal those of the default `"drop"`; the only difference is that nothing is reported as dropped. `miss_control(response = "fail")` refuses data with a missing response and names the count; `predictor = "model"` still needs an `mi(x)` formula. Full-length `NA`-padded output as drmTMB returns it is not implemented here (planned with the same follow-up as the bivariate route). New test `test/test_univariate_response_include.jl`.
