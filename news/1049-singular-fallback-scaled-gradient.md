- **The singular-Hessian fallback of the unit-free convergence test uses the diagonal-scaled gradient (#1049).** When the correlation-form Hessian is singular, `_unitfree_converged` now applies `max |g .* D| <= 1e-3` (`D = diag(H)^(-1/2)`) instead of the raw `max |g| <= 1e-3`, so the verdict no longer changes when a parameter is rescaled. The negative-eigenvalue saddle rejection and the non-finite checks are unchanged.
