- **Correction: the v0.7.0 "threaded bootstrap, demonstrated" figure was not a threading gain (#689).** The 10× over native TMB at R=199 came from a Julia session with one thread (`julia.threads` = 1), so `threads = TRUE` ran the refits serially; the figure compares warm serial Julia with TMB. `threads = TRUE` parallelises the refits only when `JULIA_NUM_THREADS` > 1 is set before Julia starts.
