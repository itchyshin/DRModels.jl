- **`spatial(1 | site)` matches `coords` to sites by label (#957, spatial half).** Row `k` of `coords` used to be taken as the `k`-th site in first-seen order of the grouping column, checked only by row count, so a coordinate matrix sorted by site id gave a different likelihood and a collapsed range with `converged = true` and no warning. `coords` is now matched by label, as `A` is: pass `ids = [site label of each row]` with a matrix, or a `Dict` keyed by site label. Coordinates for sites not in the data are dropped; a site with no coordinates is an `ArgumentError`. A plain matrix without labels keeps the first-seen convention and warns once per session. Covers the Gaussian, Poisson, NegBinomial2, Gamma and Beta (and ZeroOneBeta) `drm` methods; the bivariate route, the bridge and `bootstrap_result` do not take `ids` yet.
