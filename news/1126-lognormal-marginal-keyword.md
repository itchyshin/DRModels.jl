- **`drm(..., LogNormal(); marginal = ...)` is accepted (#1126).** LogNormal now takes the same `marginal` keyword as Poisson/Gamma/NB2/Binomial/Beta/Student instead of a raw `MethodError`. `:LA` (default) is unchanged; `:Laplace` on an ordinary `(1 | g)` returns the identical fit tagged `marginal = :Laplace` (log y is Gaussian given the group effect, so the Laplace approximation is exact); `:VA`, `:AGHQ`, unknown selectors, and `:Laplace` on other shapes throw a clear `ArgumentError`.
