- **Separation check: scale-free near rule, consistent intervals, bounded solver (fixes the #910 review).** The near-separation rule no longer flags healthy fits: the old "fitted probability within 1e-8 of 0/1 AND a Wald SE above 1e4" test was unit-dependent (it flagged a well-identified slope, z = 4.6, once its covariate was divided by 1e5) and read a failed SE as evidence. It is now scale-free: a fitted probability within 1e-8 of 0/1, a coefficient whose own contribution `|βⱼ|·range(xⱼ)` spans that whole probability range (> 36.84 on the logit scale), and Wald `|z| < 0.05`; a non-finite SE is never read as near separation. The exact check is now a Lawson–Hanson non-negative least-squares (Farkas) solve in place of the Bland-rule simplex, with the same flagged coefficients on every case tested; it is bounded by an iteration budget, and an exhausted budget warns that the check was inconclusive instead of silently reporting no separation. Flagged coefficients now carry an `Inf` vcov diagonal (rows/columns NaN), so `stderror`, `coeftable` and Wald `confint` agree on `Inf` / `(-Inf, Inf)`. Bootstrap replicate refits no longer repeat the warning. Flag semantics: a coefficient is flagged when any separating direction moves it, which can list more coefficients than R's `detectseparation`. drmTMB (#1268, PR #1442) carries the identical change. Healthy fits are unchanged.
