- **A NaN or Inf predictor on an observed-response row now errors with the column and row named (#1113).** With `(1 | g)`, Poisson, NegBinomial2, Binomial and Student returned a `DrmFit` of starting values (`loglik = -Inf`, finite-looking SEs, no error), and Gaussian and Gamma threw an unnamed LAPACK or ForwardDiff error. `drm` now raises `ArgumentError: drm: predictor `x` contains a non-finite value (NaN) at row N`. A NaN predictor on a row whose response is also missing is still dropped with that row; `predict` on `newdata` is unchanged.
