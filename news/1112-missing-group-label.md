- **A `missing` or `NaN` in a random-effect grouping column is now refused instead of silently pooled (#1112).** Before, `(1 | g)` with `g` holding `missing` fitted all those rows as one extra group (`nobs` unchanged, `converged = true`), unlike drmTMB, which drops them. Every route that reads a raw grouping column now throws an `ArgumentError` naming the column. Drop the rows first with `data = drm_listwise(formula, data)`, which gives the same fit as drmTMB.
