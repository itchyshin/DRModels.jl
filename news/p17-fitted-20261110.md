- **`fitted(fit)` now includes the random-effect modes, as drmTMB does.**
  The default is `re = :conditional`: for a fit with random effects,
  `fitted(fit)` returns the conditional fitted values (fixed part plus the
  fitted random-effect mode of each row's group), the same numbers as R's
  `fitted(fit)`. Before this change Julia returned the population-level
  values. To get the old values, use `fitted(fit; re = :zero)`. The
  keyword name matches `simulate`. `residuals(fit)` is `y - fitted(fit)` at
  the same level, with the same `re` keyword, so use
  `residuals(fit; re = :zero)` for the old response residuals.
  A fit with no random effect on the mean gives the same values under both
  settings. `predict(fit, newdata = ...)` is unchanged.
- **Rows used.** `fitted(fit)`, `residuals(fit)` (both types) and `sigma(fit)`
  return one value for each row used in the fit, so rows with a missing
  response are no longer returned (R does the same). `nobs(fit)` is the
  length. This matches drmTMB's default missing-data policy ("drop"). Its
  second policy ("include", full-length values with `NA` for the unused rows)
  is a planned follow-up and is not added here. The R bridge payload keeps one
  value per input row, as before.
- **Which fits give the conditional values.** Conditional values are
  available for: Gaussian ordinary random effects (intercepts, slopes,
  correlated blocks, several groups, a random effect on `sigma` or on both
  `mu` and `sigma` of one group), `meta_V` fits with random effects,
  Gaussian structured fits with a computed BLUP (two structured terms,
  phylogenetic slopes, the sparse and EM `phylo(1 | g)` routes), AR1 and OU
  `temporal()` fits, the adaptive-quadrature random intercepts of Poisson,
  Binomial, BetaBinomial, Beta, Gamma, NB2, LogNormal, Student, Tweedie and
  CumulativeLogit, and the crossed Laplace routes. The structured count
  routes that record their conditional field for the R bridge also give it.
  Since the P20 follow-up this includes the single `relmat(1 | g)`,
  `animal(1 | g)` and dense `phylo(1 | g)` Gaussian fits (the BLUP at the
  fitted variance components, REML included) and the `phylo(1 | g)` Laplace
  fits of Poisson, Binomial, BetaBinomial, NB2, Gamma and Beta (the inner
  mode the Laplace objective solves at the fitted parameters, including the
  `sigma ~ x` and REML variants). On the same data these agree with drmTMB
  0.8.1 `fitted()` to 1.3e-7 or better wherever drmTMB fits the same model
  (it refuses `phylo()` for the beta-binomial family). A fit with a missing
  response is refused by the dense Gaussian routes, as before; the Laplace
  routes return the used rows.
- **Agreement with drmTMB.** On the Gaussian, LogNormal and phylo routes
  `fitted(fit)` agrees with drmTMB's to 1e-6 or better on the cells checked.
  On the routes that integrate the random intercept by adaptive quadrature
  (the default for one `(1 | g)` on Poisson, NegBinomial2, Binomial, BetaBinomial,
  Gamma, Beta, Tweedie and CumulativeLogit) it differs by about 1e-4 to 5e-3 on the
  reference cells checked (Student agreed to 1e-9 on its one cell, where the group SD
  is at the boundary). The modes come from the more accurate integration (adaptive
  quadrature), while drmTMB maximises a Laplace approximation (the two
  log-likelihoods differ for the same reason).
- **Routes that keep no random-effect modes refuse the default.** These
  include the structured count and continuous routes that do not record a
  conditional field (for example a `relmat(1 | g)` or `animal(1 | g)` count
  fit), `ZeroOneBeta` with a random effect, bivariate fits with random
  effects, a random effect on `sigma` when the family mean depends on
  `sigma`, the opt-in crossed adaptive-quadrature routes, and fits made with
  `marginal = :Laplace` on one `(1 | g)` of Poisson, NegBinomial2, Binomial,
  Gamma, Beta or Student. For the last group call `fitted(fit; re = :zero)`
  for the population-level value, or refit with the default marginal for the
  conditional value.
  `fitted(fit)` then raises an error that
  names the route and points to `re = :zero`. It never returns population
  values under the conditional default.
- **Fixes after review.** A `LogNormal` `phylo(1 | g)` fit with a missing response
  returned the population values under the conditional default (and an error
  under `re = :zero`); it now returns the conditional values on the used rows,
  the same as the fit on the complete cases. `sigma(fit)` no longer shows the
  internal record that `fitted` uses. If an adaptive-quadrature group mode had
  to be reset because it was not finite, `fitted(fit)` now refuses with an
  error instead of giving that group its population value.
  `residuals(fit; type = :quantile, re = ...)` now raises an error for any
  `re` other than the default, because quantile residuals do not take it.
- **Quantile residuals and `sigma(fit)` on used rows.** On a fit with a
  missing response, `residuals(fit; type = :quantile)` and `sigma(fit)` now
  have length `nobs(fit)` (before, one value per input row, with `NaN` in the
  quantile residuals at the missing rows; for Binomial, BetaBinomial,
  CumulativeLogit and the `phylo` Laplace fits the call raised an error and
  now works). `sigma` and the quantile residuals of continuous families are
  unchanged on the used rows. For discrete families the randomised quantile
  residuals now draw one random number per used row instead of one per input
  row, so seeded values on a fit with missing rows differ from before; fits
  without missing rows are unchanged.
