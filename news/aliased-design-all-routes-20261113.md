- **The aliased fixed-effect design check now runs on every univariate route.** A design with a column that is a linear combination of others (for example `x3 = x1 + x2`) was flagged only on the Gaussian location-scale route. On Binomial, Poisson and the other families the fit came back with `is_converged` true and a finite standard error on the aliased coefficient. It now behaves as the Gaussian route and as drmTMB does: a `fixed_effect_rank_deficiency` warning, `is_converged` false, the standard error of the aliased coefficient set to NaN. The log-likelihood and the other estimates are unchanged, and a full-rank design is untouched. An aliased fit therefore also has these side effects, as on the Gaussian route: `is_converged` is false on every route; the printed coefficient table shows NaN standard errors for all coefficients, with the reason "Hessian not PD" (the real cause is the alias); `bootstrap_summary` fails in every replicate, because each refit is judged not converged; and `confint` is infinite for the aliased coefficient. The check reads the fixed-effect design of each formula part once before the fit. A predictor with missing values is checked on its complete rows. A formula or data the check cannot read is left to the route, and so is a response with missing values (the route refits on the observed rows and checks them). Bivariate and mixed-family fits are not covered yet.
