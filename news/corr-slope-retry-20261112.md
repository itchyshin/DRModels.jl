- **Gamma, Beta and Student `(1 + x | g)` no longer throw a line-search `AssertionError`.** On Julia 1.10.12, one dataset per family with a strong slope correlation stopped with `AssertionError: B > A` from the default L-BFGS line search. These routes now use the same retry as LogNormal `(1 + x | g)`: if the default call throws, the fit is retried from the start with a finite sentinel and BackTracking, then polished with the default line search. A fit that did not throw before is unchanged to the last bit. `converged` stays honest and can be `false` on a retried fit. drmTMB 0.8.1 does not implement `(1 + x | g)` for these three families, so there is no R value to compare with.
