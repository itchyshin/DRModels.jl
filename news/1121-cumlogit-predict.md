`predict` / `predict_parameters` (and their `se = true` variants) now work on `CumulativeLogit` fits (#1121). The prediction design drops the implicit location intercept, as the fitter does, and returns the location linear predictor `Xβ̂` (the cutpoints are not part of it). Previously every call threw an `ArgumentError` blaming factor levels. Note that `fitted()` for these fits is the expected score, so in-sample `predict` is not equal to `fitted`.
