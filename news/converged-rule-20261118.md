- **The converged rule (SHINICHI-1753-1118), shared with drmTMB.** `convergence_status(fit)` now has four values, first match wins, all warnings: `:not_converged` (the optimiser did not finish, the log-likelihood is not finite or is the failed-objective sentinel, or the relative gradient `max|grad nll| / max(1, |logLik|)` is above `0.1`, an uncalibrated placeholder), `:boundary` (SD near 0, `|rho12|` near 1, a Gaussian residual scale collapsed onto the data as a Heywood case, a Tweedie power at the end of its search interval; tested BEFORE the Hessian), `:degenerate` (non-PD Hessian, non-finite or inflated SE, aliased design, separation, non-existent count MLE) and `:converged`. Before, an unfinished optimiser and a sentinel log-likelihood read `:degenerate`, and a boundary fit with an unusable covariance read `:degenerate` too. New `convergence_info(fit)` returns `converged`, `convergence_status`, `boundary_params` (`(name, kind)`), `pd_hessian`, `max_gradient`, `optimizer_code` and `optimizer_message`; `check_drm` carries the same fields. `is_converged` is still `status === :converged`; the raw `fit.converged` and the lrtest warning for unconverged fits (#1413) are unchanged. Test expectations moved with the rule are listed in the pull request.
