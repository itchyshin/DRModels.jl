- **Julia 1.12 on AVX-512 AMD Zen CPUs: integer responses with `missing` no longer lose rows silently.** On Julia 1.12.6 and 1.12.7, on machines whose CPU is an AMD Zen 4 or Zen 5 (EPYC 9004 and 9005, Ryzen 7000 and 9000), a `Vector{Union{Missing,Int}}` (also `Int32`) response of 32 or more rows was read with a wrong observed-row mask: a Poisson fit on 160 rows with 3 missing values used 22 rows, with no error. This is an LLVM code-generation fault in that Julia release, not a model error. `drm` now reads the response with a loop that does not trigger it, and checks the result against the data in a separate read-only pass (one pass over the column), so a wrong mask stops the fit with a clear error instead of changing the answer. Julia 1.10 and 1.13 results are unchanged bit for bit. Test: `test/test_response_mask_j112.jl`.
