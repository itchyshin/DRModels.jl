The `oracle/` directory contains the independently authored, MIT-licensed frozen SD-prior oracle and its original manifest. From this directory, run `shasum -a 256 -c oracle/SHA256SUMS` to verify the copies. Run `OPENBLAS_NUM_THREADS=1 python3 oracle/verify.py --self-test` with NumPy to exercise the independent calculations and mutation controls. The original README describes fixture generation, fit convergence qualifications, and optional dependencies.
