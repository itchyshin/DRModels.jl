- **Bivariate `predict` reuses the training factor schema (#1000).** `BivariateDrmFormula` now carries the same `schema_cache` as the univariate formula. A `newdata` table that holds a subset of the fitted factor levels predicts those rows instead of rebuilding contrasts (or throwing a raw StatsModels error). `predict_parameters` uses the same cache.

- **`heritability` / `icc` / `repeatability` no longer report a clamped `(0, 1)` interval when the delta-method SE is not finite (#1007).** A finite but non-positive-definite `vcov` gives a negative delta variance, `se = Inf` and now `ci = (NaN, NaN)` with `status = :vcov_unavailable` (it used to be clamped to `(0, 1)`, a valid-looking interval for "no uncertainty estimate"). Fits with usable covariance are unchanged.

- **`drm(...; profile_ci = true)` is refused when the formula has no `phylo(1 | g)` on `sigma` (#1010).** `profile_ci` only precomputes the profile intervals of the Gaussian sigma-phylo location-scale routes; on every other formula it was dropped and a fit with no profile intervals came back. It now raises an `ArgumentError` naming the missing marker, as `tree`, `K`, `A` and `coords` already do (#1057). `drm_bridge_inference(method = "profile")` requests `profile_ci` only for sigma-phylo formulas, so bridge profiling of other fits is unchanged.

- **The q2 bridge entry points now reject unknown option keys, and the profile-failure error no longer recommends `method = "wald"`** (#1011, items 1 and 2). `drm_bridge_q2_phylo` and `drm_bridge_q2_known_precision` fail closed on a key outside `iterations`, `g_tol`, `fd_h`, with the same message form as `drm_bridge`, instead of dropping a misspelled key and fitting with the default. The profile-failure refusal in `drm_bridge_inference` names only `method = "bootstrap"`, the one alternative the function accepts. Item 3 (bootstrap status from very few surviving refits) stays open.

- **Confidence level and bootstrap replicate count are checked (#1018).**
  `confint`, `coeftable`, `profile_result`, `profile_curve`, `bootstrap_ci` /
  `bootstrap_summary` / `bootstrap_result`, `bootstrap_sigma_a`, `profile_sigma_a`,
  `bias_correct`, and `heritability` / `icc` / `repeatability` reject a `level`
  outside `(0, 1)` or a non-finite `level`, and bootstrap rejects `B < 1` or a
  non-integer `B`, with an error that names the argument and the value. `level = -0.5`
  no longer returns an inverted interval, and `level = 95` no longer surfaces as a
  bare `DomainError` from `quantile`. The cross-family `fit_mixed_family` route
  uses the same `level` check; its `B = 0` still means "do not bootstrap".

- **`update` repeats the estimator stored on the fit (#1008).** A REML fit stays
  REML, a non-default `marginal` stays that integrator, and a penalized MAP fit
  keeps its `penalty`. Keywords still override those stored options. An unnamed
  extra positional argument is now an error. Options that were never stored on
  `DrmFit` (`K`, `A`, `tree`, `coords`, `algorithm`, `g_tol`, `profile_ci`,
  `phylo_coupled`, `sparse`, `impute`, `missing`) are not recovered; pass them
  again. Bootstrap refits of a MAP seed forward the same stored penalty.

- **Behaviour change: parametric bootstrap now drops unconverged replicates by
  default (#962).** `bootstrap_ci`, `bootstrap_summary`, and `bootstrap_result`
  default to `check_converged = true` (previously `false`). A refit that does
  not converge is skipped: it stays out of the percentile, `status` is
  `"bootstrap_incomplete"` rather than `"bootstrap"`, and a warning names that
  status. The default `failures = :error` aborts only when a refit throws.
  Retained draws that pile up on a random-effect SD or correlation bound set
  `"bootstrap_at_boundary"` and warn as well; a dropped replicate still warns
  in that case, naming `bootstrap_at_boundary`. Gaussian location-scale,
  random-intercept, and location-scale-scale fits judge `converged` by the
  Newton step in standard-error units (`max |H⁻¹g| / SE ≤ 1e-3`) together with
  `Optim.converged` and a stop short of the iteration limit. The absolute
  `g_converged` check at `1e-8` is not part of that flag, so a change of
  predictor units does not turn a stationary fit into a failed one. A temporal Gaussian whose residual SD sits
  on the documented `sigma_ratio` boundary stays `is_converged` when the
  optimiser converged: that split is not the saturated-mean collapse the
  degeneracy bar rejects, and dropping it discarded every bootstrap replicate.
  The q=4 bridge bootstrap uses the same
  `check_converged = true` rule as the univariate bridge. Set
  `check_converged = false` only to reproduce the old intervals.

- **`update` and the likelihood-ratio tests refuse silent mismatches (#1008, #1002).**
  `update(...; method = :ML)` on a penalized MAP fit drops the stored penalty
  unless `penalty` is passed again. Passing `family` to `update` is an error
  that names the argument. `lrtest` and `lrt_boundary` error when the two fits
  have different `nobs`, different marginal approximations, or a penalized MAP
  estimate, so a missing-response or imputed refit is not compared with the
  seed as if they were the same sample.

- **`bootstrap_result` records which estimator it used, and the formula-based form can request REML, a non-default marginal or a MAP penalty (#1025).** The fit-based form already repeated a REML, `:VA`/`:AGHQ` or MAP seed fit in every replicate (#1038), but nothing on the result said so, and the formula-based form had no `method`, `marginal` or `penalty` keyword. The result now carries `estimation_method` and `marginal` (the seed fit) and `refit_estimation_method` and `refit_marginal` (the kept replicates, `:mixed` if they differ), and warns if the replicates used a different estimator. `bootstrap_result(formula, family; method = :REML)` fits the seed and every replicate by REML; `method` other than `:ML`/`:REML` throws `ArgumentError`. Existing result fields are unchanged. Tested on a Gaussian `(1 | g)` fit, B = 3: seed and replicates `:REML`, and the formula form matches the fit-based form on the same seed.

- **Phylogenetic bootstrap solver-control tests use the default `check_converged = true`.** The two EM checks in `test/test_bootstrap.jl` no longer pass `check_converged = false`. Their data now carry a real phylogenetic signal, so the EM refits stop on their own relative-loglik rule instead of running to the iteration cap with `sigma_phy` heading to zero (#1048). Test-only; no change to `bootstrap_result`.

Fix: the fixed-effect Student route now sets `converged` from the unit-free Newton step in SE units (plus `Optim.converged` and the iteration-cap check), as the Gaussian ML routes do, instead of the absolute `g_tol` gradient test. A valid fit at the Gaussian limit (degrees of freedom running to infinity) that stalled with `|g|` just above `1e-8` is no longer flagged unconverged. The other `drm_optim_converged` sites stay on #1050.

- **Bootstrap records a thrown refit and names an all-fail cause (#1052).**
  A thrown refit is stored in `failures`. The default remains
  `failures = :error` (abort after the thrown refits are recorded). Pass
  `failures = :skip` to keep successful draws and return
  `bootstrap_incomplete`. When every replicate fails the error names the
  first failure's cause. `used == 0` still errors.

- **`lrtest` / `anova` compare observation row sets, and `predict(:response)` is `invlink(Xβ)` at RE = 0 (#1053, #1092).** The likelihood-ratio nobs guard now refuses two fits that share a row count but dropped different rows (missing response or missing predictor). `lrt_boundary` uses the same helper. The `predict` docstring and the reader pages now say `:response` returns `invlink(Xβ)` with random effects set to 0 (the average group, not an average over groups).

- **The `SkewNormal` and `check_drm` docs now state the real `skew_normal_nu_wald` rule** (the note fires when any fitted `|ν̂| < 0.5`, an uncalibrated heuristic with no Wald test) instead of pointing at a drmTMB note as its source (#1060).

- **`show(fit)` now names the marginal approximation behind its `logLik`** (#1071). A random-effect fit prints e.g. `logLik (marginal :LA, default integrator, not the one-point Laplace drmTMB reports; marginal = :Laplace matches drmTMB)`, so a cross-engine logLik / AIC gap is no longer read as an error. `loglik` and every value are unchanged; fixed-effect fits and Gaussian `:LA` fits print as before.

- **Poisson (phylo / relmat / crossed) and NB2 phylo Laplace routes now build the Wald Hessian from the exact gradient (#1073).** `_fit_poisson_general_laplace`, `_fit_general_mean_laplace_nuisance`, `_fit_poisson_crossed_intercepts_laplace` and `_fit_poisson_crossed_laplace` use central differences of the route's analytic implicit gradient, with the shared `_SE_MODE_TOLS` inner-solve ladder. Poisson crossed with three random-intercept components previously understated the fixed-intercept SE by 30%. A collapsed log-SD (coordinate < −7) still takes the value-based path. This does not close #1073 (remaining J3 lanes).

- **Phylo covariate-dispersion SEs fall back when a per-observation log-sigma hits its clamp (Refs #1073).** `_fit_phylo_mean_laplace_hetero` now takes the value-based Wald Hessian when any observation's `ησ = Xσ·βσ` sits at the family's dispersion bound, not only when the phylogenetic log-SD has collapsed. The gradient-difference Hessian is undefined there (flat objective, non-flat analytic gradient).

- **`drm` drops rows with a missing predictor or response, with a warning that gives the count, as drmTMB does (#1089).** A `missing` predictor used to throw `KeyError: key missing not found` on every family, univariate and bivariate, and a missing response on the Gaussian `(1 | g)` and `meta_V` routes was refused. Those rows are now dropped (R's `na.omit`) and `nobs(fit)` counts the rows used. On the 27 raw datasets of the drmTMB t5 sweep (Gaussian, Poisson and Gamma `(1 | g)`, up to 20% missing in `y` and `x`), `nobs` matches native drmTMB in 27 of 27 cells, with logLik within 1e-10. Prior `weights` are dropped with their rows. A `relmat`/`animal`/`spatial` model whose level order the drop would change is refused by name, because its matrix is matched to the levels by position. `NaN` predictors (#1113), missing grouping labels (#1112), and missing responses on the bivariate and structured Gaussian routes keep their current handling. `bootstrap_ci` on such a fit needs the complete-case data (`drm_listwise(formula, data)`) as `data`; its length error now says so.

- **Docs: `predict` sets random effects to zero, and the default marginal approximation is named (#1092, #1070).** The `predict` and `predict_parameters` docstrings said random effects were "integrated out", and the `fitted` docstring called its value the "population/marginal mean". `predict` and `predict_parameters` return the population-level value with every random effect at zero (`g⁻¹(Xβ̂)`), the prediction for an average group, and so does `fitted` on the fixed-effect and ordinary `(1 | g)` routes of the GLM-type families (Gaussian, Poisson, NegBinomial2, Gamma, Beta, Binomial). The docstrings now say so; give the log-link marginal mean, `predict(fit, newdata) .* exp(re_sd(fit)[:g]^2 / 2)`; say that drmTMB's `predict(newdata)` also sets random effects to zero while its `fitted()` adds the random-effect modes; and list the routes and families whose stored `fitted` values differ (the Gaussian `phylo` mean route, ZeroOneBeta, CumulativeLogit, LogNormal). `test/test_predict_random_effects.jl` pins the behaviour on Poisson and Bernoulli `(1 | g)` fits. The drmTMB-parity and Getting-started pages now say that the default `marginal = :LA` uses each route's own integrator: per-group adaptive Gauss–Hermite quadrature with 5 nodes for an ordinary `(1 | g)` on most non-Gaussian means (21 for Tweedie, 41 for CumulativeLogit), a fixed 32-node grid for Gaussian `sigma ~ (1 | g)` and ZeroOneBeta, and the Laplace approximation on crossed and structured routes. They also say that the default and drmTMB log-likelihoods differ by about 0.001 to 0.24 units on the count, Beta, Gamma and Student datasets compared, with the default the closer to a 61-node reference; that `marginal = :Laplace` reproduces drmTMB (log-likelihoods to about 1e-8, estimates to about 5e-8 relative) and is for parity rather than a better default, except on the fixed-grid Gaussian `sigma` route; that log-likelihoods, likelihood-ratio tests and AIC/BIC compare only within one approximation; and which models accept `:Laplace`. Descriptions of the ordinary `(1 | g)` default as a fixed "32-node" grid, superseded by adaptive quadrature in v0.7.2, were corrected in `families.md`, `capabilities.md`, the Laplace-vs-variational guide, the Poisson/Beta/Gamma/NegBinomial2 docstrings and the `Laplace`/`AGHQ`/`MarginalMethod` docstrings; `capabilities.md` gains the missing Student `:Laplace` row; and `rosetta.md`, `model-workflow.md`, the prediction page and the temporal tutorial now describe predictions as set to zero rather than integrated over the random effects. The `ArgumentError` texts that still call the default "GHQ-32" are code and are left for a separate change.

- **Behaviour change: `simulate()` on a random-effect fit draws fresh random effects by default (#1092).** The new default `re = :marginal` uses the marginal simulator the parametric bootstrap already used (#459, #462), which matches drmTMB's default `simulate()` (`re.form = NA`). Such a fit now needs `data =`, the table it was fitted to (and `tree` / `K` / `A` / `coords` for a structured term). Without it, `simulate` throws an `ArgumentError` instead of drawing at `b = 0`. The old draw, with the random effects set to zero, is `re = :zero`. On a Poisson `(1 | g)` test fit (24 groups of 20), the across-draw variance of a group mean was 0.768 by default against 0.777 under the fitted marginal model, and 0.116 under `re = :zero`. Fits without random effects, `temporal()` fits and `simulate(fit; newdata)` draws are unchanged.

- **Beta `(1 | g)` `marginal = :Laplace` no longer returns the `-1e18` failed-fit placeholder on a good interior optimum, and its Wald SEs are no longer NaN** (Refs #1093). The shared sparse-Laplace mode finder rejected every backtracking step at its 1e-13 tolerance because the decrease fell below floating-point resolution, so it reported failure at a point that was already the mode. It now uses a rounding-tolerant acceptance test and takes the Newton step once the step is tiny and the Hessian is positive definite. `deviance(fit)` now returns `NaN` with a warning on a sentinel fit, like `aic`/`bic`/`aicc`.

- **Bivariate Gaussian `drm()` now refuses an ordinary `(1 | p | g)` random effect with an `ArgumentError` that names drmTMB (which fits it), and refuses `marginal = :Laplace` (or any value other than the default `:LA`) with an `ArgumentError` instead of a bare `MethodError`.** The capability table lists the unsupported cell (#1094).

- **LogNormal `phylo` / `relmat` / crossed fits: `fitted` is now the response-scale median, and the quantile residual is the closed-form marginal (#1102); the dense `:gls` Gaussian `phylo(1 | g)` route no longer emits the structured-PIT warning (#1104).** These LogNormal fits kept the Gaussian-on-log(y) means, so `fitted` was on the log scale and `residuals(type = :quantile)` took log of it again (max error 9.9 against the closed form on a 32-tip tree). `fitted` is now `exp(Xb + u)` like the plain route, and the phylo PIT is `Phi((log y - x'b) / sqrt(se^2 + sb^2 C_ii))`. The `fitted` docstring now says which routes return the population mean `Xb` and which the conditional `Xb + u`.

- **Gaussian (and LogNormal) quantile residuals with a lone mean random intercept now return the exact z-score (#1103).** The marginal is `N(μ, σ² + σ_b²)` (or the log-y form for LogNormal). The previous `Φ⁻¹(Φ(z))` round trip lost upper-tail precision and capped `|r|` at about 8.13. At `σ_b/σ = 10` the round-trip error over `|z| ≤ 4` was about 0.12; the residual now matches `z` to machine precision. Other families still use the PIT plus `Φ⁻¹`.

- **Gaussian `(1 | g)` quantile residuals are now evaluated in closed form (#1103).** The residual is `Φ⁻¹(Φ((y − Xβ̂) / √(σ̂² + σ̂_b²)))`, replacing the 32-node Gauss–Hermite mixture, which was off by 6e-3 at σ̂_b/σ̂ = 4 and by 0.12 at 10. Structured (phylo / relmat / spatial) effects are unchanged.

- **`convergence_status` is shared with drmTMB, and `is_converged` is true only for an interior optimum (FX3b; #1109, drmTMB #1554).** `convergence_status(fit)` returns `:converged`, `:boundary` or `:degenerate` by the same numeric rules, in the same order, as drmTMB PR #1564: optimiser flag and a finite log-likelihood above `-1e15`; the Poisson / NB2 MLE-existence screen and the Gaussian scale collapse; a finite, positive-definite covariance with finite standard errors; no standard error at least 50 and at least 1000 times the median of those below 50; then `:boundary` for any `|rho12| > 0.98` or random-effect SD below `1e-4`. A fit fitted with `se = false` (or `q4_vcov = false`) skips the covariance rules, as drmTMB does for `drm_control(se = FALSE)`, so a skipped covariance no longer reads as a failed one. `is_converged(fit)` and the new alias `converged(fit)` are `true` only for `:converged`, so a boundary fit is now `false` (breaking, as in drmTMB). `show`, `check_drm` and the bridge report the status. The bridge's `converged` key, which drmTMB reads as its optimiser flag, is `false` when the Poisson / NB2 MLE does not exist and stays `true` for a boundary fit (#1129). Bootstrap and profile refits, frozen margins and `heritability` still accept a boundary optimum. drmTMB's design-rank rule is not applied, because a fit does not store its design; drmTMB does not apply it to Julia-engine fits either.

- **Poisson and NB2 fixed-effect fits now warn when the MLE does not exist (#1109).** An all-zero response or a design whose positive counts lie only on a face of the covariate cone (Haberman 1974; Santos Silva and Tenreyro 2010) is screened with the same cone already used for binomial separation, using `s = 1{y > 0}` and `ntr = 1 + s`. The fit is still returned; flagged location coefficients have `Inf` standard errors. `convergence_status` reads such a fit as `:degenerate`, so `is_converged` is `false` (FX3b; drmTMB #1554).

- **A rank-deficient fixed-effect design is no longer reported as a converged fit with finite SEs (#1110).** `sigma ~ 1 + x + z` with `z = 2x + 1`, or a duplicated column, in the `mu` or `sigma` design of a Gaussian fit now warns once (`fixed_effect_rank_deficiency`, naming the parameter block and the aliased coefficients), gives `is_converged(fit) == false` (the raw `fit.converged` flag is unchanged), reports `NaN` SEs for the aliased coordinates, and sets `check_drm(fit).ok = false` with a new `fixed_effect_rank_deficiency` field. The vcov guard no longer blames a variance boundary for the singular Hessian in this case. The log-likelihood and the pseudo-inverse covariance of the identified coefficients are unchanged. Only the Gaussian route is covered so far; the check is `DRModels._check_fixed_design_rank` in `src/design_rank.jl`, one line to add to another family's `drm` method. Twin of drmTMB #1470 / #1478.

- **A numeric predictor typed `Vector{Union{Missing,Float64}}` with no `missing` value is now fitted as continuous** instead of being dummy-coded as a factor (one coefficient per distinct value, with a plausible-looking converged fit when the predictor has few values). `drm` narrows such a predictor column before building the design, and `drm_listwise` on complete data now returns the narrowed column. A `Vector{Any}` column, such as the bridge's R `factor(x)`, stays categorical (#1111).

- **A `missing` or `NaN` in a random-effect grouping column is now refused instead of silently pooled (#1112).** Before, `(1 | g)` with `g` holding `missing` fitted all those rows as one extra group (`nobs` unchanged, `converged = true`), unlike drmTMB, which drops them. Every route that reads a raw grouping column now throws an `ArgumentError` naming the column. Drop the rows first with `data = drm_listwise(formula, data)`, which gives the same fit as drmTMB.

- **Gaussian `(1 | g)` with `sigma ~ z` no longer throws `ArgumentError: matrix contains Infs or NaNs` when the residual sigma collapses to 0** (for example when every group has one row). The fit now warns, withholds the Wald covariance (all `NaN`) and reports `converged = false`, as the fixed-effect Gaussian route has since #968 (#1114).

- **`lrt_boundary` now documents that the 50:50 chi-bar p-value is conservative for Poisson vs NegBinomial2 (#1116).** In 500 Poisson-null replicates (n = 250) it rejected about 3% of the time at nominal 5% (the naive `lrtest` χ² gave 1.8%). The mixture weights are unchanged; this is a docs-only change.

- **Ordinary `(1 | g)` profile CIs at the SD floor are `[0, u]`, never a throw or `(-Inf, Inf)` (#1117).** When the lower arm of a `:resd` profile reaches the numerical log-SD floor without an LR crossing, `confint(..., method = :profile)` now reports the SD-scale boundary interval `[0, u]` (drmTMB `profile.boundary`). A pseudo-inverse SE of ~1e-19 no longer seeds a microscopic bracket that never leaves the floor. Interior random-effect SDs stay on the working `log σ_b` scale. Percentile bootstrap under-coverage of the sigma intercept (#1119) is a methods choice, not changed here.

- **`lrt_boundary` now documents that the chi-bar p-value for the Gaussian `(1 | g)` test is conservative with few groups (#1118).** In 500 null replicates (25 groups of 12) it rejected about 3.4% of the time at nominal 5% (the naive `lrtest` χ² gave 1.2%); statistics match `drmTMB` to about 1e-8. The mixture weights are unchanged; this is a docs-only change.

- **`bootstrap_ci` warns that percentile intervals for `sigma` terms in a mixed model are too narrow, and recommends profile intervals (#1119).** In a simulated Gaussian location-scale model with a mean random intercept, the 95% percentile interval for the `sigma` intercept covered 83 to 90% of the time (one-sided misses), while profile intervals covered 92 to 94%. The percentile interval is kept unchanged; the warning fires once per call when the fit has random effects and a `sigma` coefficient row, and the `bootstrap_ci` docstring and the capabilities page say the same.

- **`predict` and `predict_parameters` work on `CumulativeLogit` fits (#1121).** They threw an `ArgumentError` on every `newdata`, the training data included, because the prediction design rebuilt the location intercept that the ordinal fitter drops (the cutpoints absorb it), and the error blamed factor levels. Prediction now drops that column as the fitter does and returns the location linear predictor X·β, on the fixed, `(1 | g)` and `se = true` routes. The values are identical on the link and response scales, as in drmTMB: on the sweep-oct16 t6 fixture they match drmTMB 0.7.1 to 2e-11, with SEs within 1e-8. This is not `fitted(fit)`, which is the expected category score. A `newdata` with a subset of the factor levels is still refused (#1000).

- **`docs/src/capabilities.md` now lists `ZeroOneBeta()` mean random intercepts, `(1 | g)`, as supported** (the row said fixed effects only; the fit has worked since #723). `sigma`, `zoi` and `coi` stay fixed-effects-only. A test pins the fit and the docs row (#1122).

**`drm(…, SkewNormal())` with a missing/NaN response now goes through the same observed-rows wrapper as every other univariate family:** it warns, fits on the observed rows, and rebuilds the full input rows, so `fit.scales` / `predict` have one entry per input row (previously only the observed rows were kept). (#1123)

- **`drm(..., LogNormal(); marginal = ...)` is accepted (#1126).** LogNormal now takes the same `marginal` keyword as Poisson/Gamma/NB2/Binomial/Beta/Student instead of a raw `MethodError`. `:LA` (default) is unchanged; `:Laplace` on an ordinary `(1 | g)` returns the identical fit tagged `marginal = :Laplace` (log y is Gaussian given the group effect, so the Laplace approximation is exact); `:VA`, `:AGHQ`, unknown selectors, and `:Laplace` on other shapes throw a clear `ArgumentError`.

- **Beta location-scale fixed-effect fits now polish an early optimiser stop (#1127).** On `betareg::GasolineYield` (`yield ~ temp + batch`, `sigma ~ batch`, 10 batches of 2-4 rows) LBFGS used up its 1000 iterations with the gradient near 50 and stopped 0.0168 nats below the drmTMB / glmmTMB optimum (92.0596218475). A Newton step sequence from the stop point (ForwardDiff gradient and Hessian) now reaches it in 4 iterations, and the fit reports converged. The polish is kept only if the objective is no worse and the gradient reaches `g_tol`, runs only when the first run missed `g_tol`, and is skipped when `DRMControl` sets `maxit` / `start` / `multi_start` / `optimizer`; a seeded panel of few-rows-per-level fits returns every degenerate fit exactly as before.

- **A crossed-random-intercept fit with an estimated dispersion (Beta, NB2, Gamma, BetaBinomial) that ends on the 1e18 failed-inner-solve sentinel now says so** (Closes #1142). Previously only the NaN-vcov warning appeared. The new warning is separate, silent inside bootstrap and profile refits like the other boundary warnings, and changes neither the estimates nor `converged` (already `false` there).

Fix: REML Gaussian fixed-effect route (`method = :REML`) now sets `converged` from the unit-free Newton step in SE units, as the ML route does, instead of the absolute `g_tol` gradient test; a fit at the optimum is no longer flagged unconverged, a truncated fit still is (#1170).

- **`convergence_status` now returns `:degenerate` for a separated fixed-effect Binomial fit even with `se = false` (#1186).** The fixed-effect Binomial fitter records (quasi-)complete separation from the existing `_detect_separation` screen as `fit.geometry === :binomial_separation`, the twin of drmTMB `binomial_separation` in `drm_mle_nonexistent()`. Step 2 of `convergence_status` reads it, so the verdict no longer depends on the Inf standard errors that `_separation_guard` sets (and that are skipped when SEs are off). Estimates, vcov and the guard warning are unchanged; the bridge `converged` key follows through `fit.geometry === :ok`.

- **NB2 crossed `(1 | g) + (1 | h)` fits with a random-effect log SD at its -8 clamp now report finite standard errors for the identified parameters (Refs #1190).** The objective is flat in a clamped log SD, so that Hessian row is near zero. The value-path pseudo-inverse reported a meaningless SE for the clamped coordinate (114 and 130 on the #1088 `nb2_runoff_s7_n1500` set) and, when finite-difference noise tipped one eigenvalue negative, an all-`NaN` covariance on a fit with `converged = true` (`nb2_runoff_s7_n800`). The clamped log SD is now held fixed at the boundary and the Hessian of the remaining coordinates is inverted, from central differences of the exact gradient. On `nb2_runoff_s8_n1500` the fixed-effect and log-dispersion SEs agree with drmTMB's sdreport to 1e-6. The clamped coordinate has `NaN` variance and covariances, with a boundary warning. `convergence_status` reads a log SD within 1e-3 of the -8 floor as `:boundary` (the floor `e^-8 = 3.4e-4` never fell under the `1e-4` cut) and applies its covariance rules to the remaining coordinates, so these fits are `:boundary` rather than `:converged` or `:degenerate`. Other routes with a clamped log SD are unchanged.

- **`show` and `coeftable` no longer print Wald SEs for an unconverged fit or a non-positive-definite Hessian (#1193).** When `is_converged(fit)` is `false` or the covariance is not positive definite, the printed Std.Error, z, p and Wald interval columns are `NaN`, and `show` prints one line saying why (for example "Wald SEs withheld: the Hessian is not positive definite."). drmTMB refuses `vcov()` in these cases. On the #1127 GasolineYield fit before its Newton polish, `show` printed 21 finite SEs on an unconverged Beta location-scale fit. `stderror(fit)` and `vcov(fit)` are unchanged and still return the Hessian-based values; estimates are still printed.

- **`marginal = :VA` fits now check that every group's inner variational solve is stationary, and report `converged = false` (with a warning) when one is not (#965).** Each `:VA` fitter (Poisson, Binomial, NegBinomial2, Gamma, Beta `(1 | g)`) profiles every group's variational mean and log-variance with an inner Newton solve. Before this change that solve was a fixed 25- or 30-step unroll with no stationarity test, so `converged` could be `true` while a group's inner point was far from its optimum. On base, a four-group Poisson fit with one all-zero group (`y = [0, 0, 0, 0, 12, 147, 1778]`) reported `converged = true` at `coef = [37.60, 3.67]`, 7.5 nats below the variational optimum at `[2.837, 1.430]`; a Gamma fit with one high-leverage group did the same 5.45 nats short. The inner solve now caps each step along its own direction, damps only a Hessian that is not negative definite, takes full Newton steps close to the maximum, and continues past the fixed unroll (to at most 200 steps) until the squared Newton decrement is at most 1e-14, or below the rounding error of the group ELBO when the solve can go no further. The NB2, Gamma and Binomial kernels, the Beta kernel above precision 50, and the Poisson inner Hessian are rewritten without numerical cancellation; the old NB2 kernel gave impossible positive ELBOs near the Poisson limit (+2577 on a simulated fit that reported `converged = true`, +3539 on the `test_vcov_guard.jl` fixture). On 119 simulated fits across the five families the estimates move by at most 1.1e-9 and the ELBO by at most 3e-11, apart from two random-effect log-SDs already at the zero-variance boundary (below −19, with an unchanged ELBO); in one of those, an NB2 fit, the outer optimiser now stops with its gradient just above tolerance (3.5e-8 against 1e-8), so the fit reports `converged = false`. On 540 fits with large random-effect SDs, 19 NegBinomial2 fits that stopped on a line-search error on base now complete. Beta fits at large precision can take longer (16.7 s → 19.6 s in one measurement at φ = 1e4). `:VA` has no drmTMB counterpart (TMB is Laplace-only), so there is no R parity to state.

The multi-component closed-form route took a dense QR of the (n + q) × q stacked design on every objective and gradient call; it now uses a sparse QR (the sparse Cholesky factor of the Woodbury capacitance, formed without squaring the condition number, so the #835/#837 cancellation guard is kept) and a Takahashi selected inverse for the analytic gradient. Estimates, logLik and BLUPs are unchanged (identity to ≤ 1e-8, pinned in `test/test_multi_re_sparse_kernel.jl`). For q above 200 random-effect columns the Wald vcov is a central difference of the exact analytic gradient instead of ForwardDiff through the dense objective. Timings: `bench/bench_crossed_sparse_977.jl`.

An ultrametric tree is fitted at unit height (an exact reparameterisation) and the fit records `phylo_scale = :correlation`, so `re_sd(fit; scale = :drmtmb)` is a no-op there and the tree-height warning no longer fires. A non-ultrametric tree cannot be standardised by one rescaling, so it stays on the raw scale with the warning. The same applies to `method = :REML`, `algorithm = :em`, and to `drm_phylo_penalty(sd_u = ...)`, which is now read on the correlation scale on this route. Code that multiplied `re_sd(fit)` by `sqrt(phylo_tree_height(tree))` on this route must drop that factor.

- **Gaussian `phylo(1 | g)` quantile residuals are now the population-level (marginal) PIT (#995, #996).**
  - **What was wrong.** The sparse and conjugate-EM routes store the BLUP-conditional mean in `fitted()`. The quantile residual integrated σ_b around that mean, counting the random effect twice. It also used σ_b² for every tip, although a tip's prior variance is σ_b²·C_ii on a raw branch-length tree.
  - **What it does now.** `residuals(fit; type = :quantile)` centres on the fixed-effect mean `Xβ̂` and uses σ_b²·C_ii per tip, evaluated in closed form, so it equals `(y − Xβ̂) / √(σ̂_e² + σ̂_b² C_ii)` to rounding. In the upper tail, the Φ⁻¹(Φ(·)) round trip shared by every family keeps that to about |r| ≤ 4 and caps |r| at 8.13. It no longer warns.
  - **Why not quadrature.** The 32-node Gauss–Hermite mixture used for other random intercepts is not accurate enough here: its residual error is 6e-3 at σ̂_b √C_ii / σ̂_e = 4 and 0.12 at 10.
  - **Unchanged.** The dense structured fallback keeps the warning, a known false positive (#1104).
  - **Twin note.** drmTMB 0.7.1's quantile residual for this model is conditional on the phylo modes, `(y − Xβ̂ − û)/σ̂`, although its documentation describes a fixed-effect-only one. The two engines therefore differ by design (max 1.46 and 3.93 on the cases in `docs/dev-log/evidence/2026-10-16-995-phylo-quantile-residual-parity.md`), while agreeing to about 1e-9 under either convention. The drmTMB-side decision is tracked in #1101.
- **`fit.ranef` on these fits is now a dict-like `LocOnlyRanef` that also carries `Xβ̂` and the tree (#995).**
  - It has the same `group => BLUPs` entries, and `ranef(fit)` still returns that `Dict`.
  - LogNormal `phylo(1 | g)` fits reuse the Gaussian route on log y, so they carry one too. Their quantile residuals are unchanged and still warn; they are mis-calibrated, as before this change (#1102).
  - The EM route now stores its BLUPs as well. As a result `ranef(fit)` works on it, `r2_constant_sigma` refuses it as a random-effects fit (it used to return 1 − RSS/TSS), and the variance-boundary diagnostic now covers it.
- **The per-tip variance C_ii behind that residual costs O(p) (#995).**
  - It is the diagonal of the root-conditioned tree covariance, read from a Takahashi selected inverse and cached on the fit.
  - It takes about 1 kB per tip: 0.01 s at 16,384 tips and 0.21 s at 262,144.

- **Non-Gaussian `phylo(1 | g)` quantile residuals use the per-tip variance `sigma_b^2 * C_ii` (#996, with #1102 already closed by #1154).** The Poisson, NegBinomial2, Binomial, Gamma, Beta, BetaBinomial and ZeroOneBeta Laplace phylo routes now keep the tree diagonal `C_ii` on the fit, so `residuals(type = :quantile)` integrates tip `i` over `N(0, sigma_b^2 * C_ii)` around the population-level mean, as the Gaussian sparse and EM routes do (#1078), instead of `sigma_b^2` for every tip. On a raw branch-length tree the residuals were mis-calibrated by up to about 0.7 on the normal scale (tree height 3.45); they are now equal to an independent quadrature reference, and the structured-PIT warning no longer fires for these fits. `ranef(fit)` still refuses these fits (no conditional modes are stored).

- **The bridge payload exports the conditional structured field for relmat, animal and spatial mean fields (batch 34).** A new `conditional_structured` payload key carries `eta_re`, the per-row link-scale contribution of the field at its inner Laplace mode (data row order), and `modes`, the mode of each field component in first-seen group order (the row order of the `K` / `A` / `Q` matrix). drmTMB rebuilds `fitted()` and `residuals()` from it, so they are now the conditional mean as in native drmTMB instead of the population-level value. Fitters changed: the Gaussian structured SD route (`report_sd`, ML; the exported mode is `b = u / sd`, the same latent scale as the other families), the Poisson, NB2 and Gamma structured SD Laplace fitters (relmat, animal and coordinate spatial, intercept and slope; Poisson `Ainv`), the Binomial related-matrix SD Laplace fitter (relmat, animal `A` or `Ainv`, spatial; logit, probit, cloglog) and the Binomial animal q2 fitter (two modes, intercept and slope). The mode is a fresh inner solve at the converged `theta`, not the last finite-difference stencil point; in the NB2 fitter it is taken before the objective is stored because `laplace` writes the boxed `value` shared with that function (the first version of this change, with the call just before `DrmFit(...)`, moved the NB2 log-likelihood by 28). `DRModels.structured_conditional(fit)` returns `(eta_re, modes)`. Not exported, so unchanged: phylogenetic fields, Binomial fields combined with an ordinary random effect, mesh and crossed routes, the Gamma animal intercept-plus-slope route. DRModels.jl's own `fitted(fit)` and `residuals(fit)` stay population level. New `test/test_structured_conditional_export.jl` checks `modes` and `eta_re` against a hand-built dense Newton oracle (hand-derived per-family derivatives, no fitter code) on shuffled-row fixtures for Gaussian, Poisson, NB2, Gamma and Binomial, intercept and slope, at 1e-6 fixed beforehand, and that the stored objective equals `nll(theta_hat)` to 1e-4. No calibration or broad parity claim.

The capabilities page now retains the R-bridge qualification inside its table cell and distinguishes numerical testing from a complete worked analysis. REML and interval statements retain their route-specific evidence limits.

# Current documentation and examples

Public examples now use the formula constructors and keyword arguments accepted by the package. API documentation states the integration defaults for each route. Refusal messages describe those existing defaults without changing the numerical algorithms or supported models.

Manual and README claims distinguish recorded numerical checks, worked examples, and repeated-simulation evidence. The benchmark discussion separates retained fixtures and records that both packages reached 10,000 species in the historical scaling grid. Historical reports remain unchanged.

The control starting-vector hint refers to the retained coefficient-label field instead of a nonexistent accessor. The routed reference now exposes the control-report and log-likelihood alias documentation, shared prepared-fit defaults, and finite-state summary and imputation semantics.

- **Experimental fixed-effect priors.** Normal and ridge priors are available
  for Gaussian `mu`/`sigma` and binomial-logit `mu` fixed-effect models.
  `resolve_priors` previews selected design columns, and penalized fits report
  data likelihood separately from the prior contribution. Random-effect SD
  priors and posterior sampling are not included; interval calibration has
  not been established.

- **`predict_parameters(:response)` inverse links for Student ν, SkewNormal ν, and ZeroOneBeta μ** (sweep-oct16 t6). `_param_response` mapped every non-Tweedie `:nu` through `exp` and left ZeroOneBeta `:mu` on the identity. Student ν is now `2 + exp(η)` (matching `fit.scales[:nu]`), SkewNormal ν is identity (slant α), and ZeroOneBeta μ is `logistic(η)` (interior beta mean). `_link_deriv` follows the same three maps so delta-method SEs stay consistent. LogNormal μ (Julia `exp(η)` median vs drmTMB identity / log-Y μ) is a methods choice and is unchanged.

- **`simulate(fit; newdata)` draws one row per newdata row** (sweep-oct16 t6; twin of drmTMB #1536). The training-row call is unchanged. Draws are population-level (`predict_parameters`, RE = 0). Temporal fits refuse `newdata`. Binomial/BetaBinomial recycle a constant `trials` or require a `trials` column.

- **Convergence and covariance status no longer over-claim (lane J2; #1024, #1047, #964, #956, #968, #961, #949, #1003, #1005, #1007, #1023, #952, #978, #959).** Inner Laplace mode cap exits, EM stops, temporal restarts, raw-inverse Wald sites, non-finite Hessians on constant or badly scaled responses, the location-only `resd` profile, sentinel-ending fits and the `locscale` Nelder-Mead fallback now report failure or `converged = false` instead of success. `show`, `check_drm` and `bridge_diagnostics` use `is_converged`. `heritability` / `icc` gain a `status` field and warn on non-converged, penalised or degenerate fits. - **The relatedness matrix `A` is matched to the data by label (#957).** Pass `A` as a table whose column names are the labels, or as a matrix with the new `ids = …` keyword, on the Gaussian, Poisson, NegBinomial2, Gamma, Beta and ZeroOneBeta `drm` methods. The guard now admits `offset(...)` in the Poisson mean on every route and leaves the route-level refusals in place: no `(1 | g)`, a random slope, crossed or structured effects, `zi`/`hu` and `marginal = :VA` on Poisson, and any `offset(...)` on another family or in a non-mean formula, are still `ArgumentError`s or explicit errors, never a free coefficient.

- `DRMControl(optimizer = :lbfgs)` and `DRMControl(optimizer = :bfgs)` now select Optim.jl's named method directly on the fixed-effect univariate ML routes and Gaussian ML with one mean random intercept. `:default` keeps each route's previous optimizer and restart policy. `control_info(fit)` records the requested and actual method, every attempted start, the selected stage and native stopping diagnostics. Unqualified latent, bivariate and REML routes reject an explicit choice. Fit-based profile and bootstrap entrypoints refuse explicitly selected fits before refitting; Wald intervals remain available. No convergence or inference advantage is implied by selecting a method.
