# After-task: `offset()` holds a fixed coefficient of 1, or refuses (#938, lane f13)

## 1. Goal

`offset(z)` was silently estimated as a free coefficient on every route except
fixed-effects `Poisson()` (Owls NB2 `(1 | nest)` 0.65, Owls Poisson `(1 | nest)`
under `marginal = :Laplace` 0.54, Owls NB2 `sigma ~ Food` 0.73). The fitted model
was not the one asked for. Required: hold the offset at 1 where the route can,
refuse by name where it cannot, never put it in the design matrix or θ.

## 2. Cause

`offset` is a bare identity function; only `drm(::Poisson)` called `_extract_offset`,
and only after the `marginal = :Laplace` early return. Everywhere else the marker fell
through `@formula` as a numeric column named `offset(z)`.

## 3. Implemented

- **Choke point.** `_design` (the only builder of fixed-effect design matrices;
  `modelcols` is called nowhere else in `src/` outside the joint-missing frontend,
  which already refuses offsets) throws an `ArgumentError` if an `offset(...)` term is
  still in the right-hand side it is handed. Routes that apply an offset strip it
  first, so reaching `_design` with one means "not held fixed". This covers every
  family and every dpar (`sigma`, `nu`, `zi`, `hu`, bivariate).
- **Applied (coefficient fixed at 1, absent from `Xμ` and θ).**
  - `NegBinomial2()` fixed effects (`_fit_negbin2`) and one ordinary `(1 | g)` under
    the default `:LA` (`_fit_negbin2_ranef`).
  - `NegBinomial2()` and `Poisson()` `(1 | g)` under `marginal = :Laplace`
    (`_drm_ordinary_laplace`; the two shared kernels `_poisson_phylo_laplace_fg` and
    `_phylo_mean_laplace_nuisance_fg` gained an `offset` keyword that only changes
    `η0`, so the analytic gradient is unchanged).
  - `Gaussian()` (identity link): the fit of `y - offset`; the offset is added back to
    `means[:mu]` / `obs[:mu]` and the stored formula is the user's, so `predict`
    strips and re-applies it (`_predict_offset`, #1006).
- **Refused by name.** NB2: VA, crossed, correlated slope, structured, `zi`/`hu`,
  coupled location-scale. `:Laplace`: Gamma, Beta, Binomial. Gaussian: missing/NaN
  responses. Any offset in a non-mean formula, and every family not listed above,
  through the `_design` guard.

## 3a. Decisions and rejected alternatives

- A per-family refusal call (as in #1057) was rejected for the catch-all: it touches
  about 25 files and conflicts with #1057 and #1062. The `_design` guard needs none;
  the cost is that its message names the formula and response, not the family. The
  routes this PR implements name their own route.
- Gaussian: shifting `y` is exact for every Gaussian mean structure (random effects,
  structured, `meta_V`, REML), so one wrapper covers them all; the fitted-mean
  restoration refuses if `means[:mu]` is not one value per row.
- Offsets in `sigma` are refused, not implemented: no parity oracle exists and the
  route needs its own kernel threading.
- `offset =` as a keyword stays unsupported (`MethodError`).

## 4. Not done / limits

- **No local execution.** The authoring container had no Julia and no R. Everything
  here was written against the source and is verified only by CI.
- Parity row on Owls against drmTMB (coefficients, logLik, both commits, both
  convergence flags) needs an R run on another host.
- Bridge (`src/bridge.jl`, `R/julia-bridge.R`) is separate: stacked on #1068 and
  drmTMB#1533.
- Post-fit code that rebuilds a design from `fit.formula` (for example the LSS
  marginal simulator) now meets the `_design` guard on an offset fit and throws; it
  previously failed on a design-name mismatch.
