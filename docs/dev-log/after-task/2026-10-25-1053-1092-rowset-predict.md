## 3a. Decisions and rejected alternatives

- Row fingerprint from `fit.obs`, not a new `DrmFit` field. Observed-rows
  fits store NaN on the original length (`_with_full_response_rows` /
  `_with_full_fixed_gaussian_rows`); listwise drops subset the table. A first
  draft compared mask and values as one pair and then refused a valid
  `lrt_boundary` on the same missing row, because Gaussian `(1 | g)` listwise
  drops and the fixed-effect route pads. The fingerprint now compares finite
  values always, and the mask only when both fits store the same length.
  Adding a stored row-index hash would touch every constructor.
- Test written and run red on the count-only guard (6 pass, 3 error), then the
  guard was changed and the same file went 16/16 green.
- Docs-only close of #1092 on top of merged #1100 (that PR used Refs, not
  Closes). The remaining work was the explicit `invlink(Xβ)` sentence the
  issue asked for, copied into `docs/src`.
