# Two-effect adaptive quadrature near a singular covariance

A Julia 1.10 bounds-checked Gamma correlated-slope fit produced a stored log likelihood about 2.389 below an independent numerical integral at the same parameter vector. The second Cholesky diagonal was approximately 6.35e-10. The previous calculation formed an ill-conditioned random-effect precision matrix; a two-dimensional Float64 Schur complement lost substantial precision on this example.

The q=2 path now transforms the random effect to standard-normal coordinates. An orthogonal rotation preserves the orientation of the existing tensor-product quadrature rule. Returned modes and warm starts remain on the original random-effect scale. A lazy transformed design avoids copying all rows for each group. Other quadrature dimensions retain their previous calculation. Zero and non-finite diagonal probes retain the original impossible-point handling.

A dense Gaussian reference checks likelihood, gradient, full Hessian and random-effect mode. It also checks a warm start, zero scale and allocation for a small group within a large design. Frozen Gamma values guard the finite-rule orientation at four interior points. Independent adaptive integration with a second quadrature dimension checked the boundary Gamma likelihood; higher-order quadrature and finite differences checked its gradient at two points. The existing correlated-slope and selected crossed-family tests passed on the numerical prototype. Source-pinned full-suite, hosted, performance and release reviews remain required.

A small 100-call timing probe measured extra q=2 allocations and elapsed time, so this change does not claim a speed improvement. The test is an engineering check of particular models and parameters, not a coverage or uncertainty-calibration study. Open PR #1359 touches this source and its branch was not changed.
