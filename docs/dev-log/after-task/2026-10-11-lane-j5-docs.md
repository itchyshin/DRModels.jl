# After-task: lane J5 documentation fixes (docs-only)

## 1. Goal

Make the README and the docs pages match current behaviour on `main` for the
21 documentation issues assigned to lane J5 of the 2026-10-11 bug-fix
campaign, writing for an applied ecology/evolution reader. No code changed.

## 2. Implemented

- README restructured: plain definition and parameter/keyword table first,
  then install (Julia 1.10+), the first model with Julia-syntax notes, the R
  (drmTMB / glmmTMB) equivalent and DataFrame use, a short capability summary,
  then the benchmark, engine details and contributor notes (#1029–#1035, #988).
- Getting started: definition before the status box, `mu` / `log_sigma`
  variable names, Julia-syntax and DataFrame notes, glmmTMB mapping, extra
  package install line, convergence-flag caveat (#1031, #1034, #1035, #987, #950).
- Convergence and boundary pages: what a `true` flag does not prove,
  `grad_source` / `ok`, Student `nu` and `coi` at a limit, and replacement of
  the `g_tol` advice that cannot add iterations (#947, #987, #993).
- Capability rows and model pages: integrator descriptions corrected to the
  per-group adaptive quadrature in `src/adaptive_ghq.jl` (#1001); dispersion
  cap on crossed/structured NB2/Gamma/Beta/BetaBinomial routes (#992);
  ZeroOneBeta `coi` identification (#986); spatial range estimated here but
  fixed at the median distance in drmTMB (#991); route-dependent phylo SD
  scale (#990); conditional GLS SEs on the sparse phylo-mean route (#989);
  crossed Gaussian size limit (#988); temporal term only in drmTMB's
  development version (#958).
- Reference: `bridge_diagnostics` added to a public `@docs` block; prose entry
  for `@formula`, `drm_formula` and `offset` (#985).
- Install notes for `Distributions` / Makie on each page that loads them (#950).

  the engine-internal exports in #985 need an owner decision (document in a
  public page or stop exporting).

  the earlier fixed 32-node grid: the adaptive default landed 2026-09-29,
  after those measurements (2026-09-25), and they have not been repeated.
- #984 was already fixed on `main`; the `get-started.md` stub in #1032 no
  longer exists. No text changed for those.
