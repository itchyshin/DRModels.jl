# Changelog

The changelog mirrors [`NEWS.md`](https://github.com/itchyshin/DRModels.jl/blob/main/NEWS.md)
in the repository root. See there for the per-version history; the live work
ledger is [GitHub Issues](https://github.com/itchyshin/DRModels.jl/issues).

A PR adds its own entry as a small fragment file under
[`news/`](https://github.com/itchyshin/DRModels.jl/tree/main/news) rather than
editing `NEWS.md` directly — see `news/README.md` for the convention.
`tools/assemble_news.jl` folds the fragments into `NEWS.md`'s `## Development`
section at release time.
